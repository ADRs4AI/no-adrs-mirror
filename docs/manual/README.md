# The no-adrs-mirror manual

Step-by-step guides for humans. Each page is one sitting; do them in order the
first time.

1. **[Getting started](01-getting-started.md)** — from nothing to a private
   mirror you can read, in four steps (preview first, always).
2. **[Going public](02-going-public.md)** — `approved_paths`, the one flip
   that is always yours, and what the world sees after it.
3. **[Troubleshooting](03-troubleshooting.md)** — every failure this Action's
   own first runs hit, with the exact fix (the errors teach; this page is
   their index).

The [README](../../README.md) is the reference (every input, every mode);
these pages are the path. Questions: [Discussions](https://github.com/ADRs4AI/community/discussions) ·
Issues on this repo.
